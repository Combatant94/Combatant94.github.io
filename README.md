## Host at combatant94.github.io
1. On GitHub create a PUBLIC repository named exactly `Combatant94.github.io`.
2. Upload everything inside this folder to the repository root (index.html must be at root).
3. Commit to `main`.
4. Open Settings > Pages.
5. Under Build and deployment choose `Deploy from a branch`.
6. Select `main` and `/ (root)`, then Save.
7. After deployment the portfolio should be at https://combatant94.github.io/
